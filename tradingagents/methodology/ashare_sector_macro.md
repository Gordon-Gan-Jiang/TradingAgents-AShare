# A 股行业轮动与宏观环境方法论

> 与 FinSkills「行业轮动 / 宏观」类 Skill 对齐：**先定总量与风险偏好，再落到行业相对强弱**。

## 1. 总量与政策（国内优先）

- 关注 **信用与货币** 边际：社融、M2、LPR、汇率与外资流向（若数据可得）对 **风险资产偏好** 的含义。  
- **产业政策**（新质生产力、设备更新、能源转型等）对板块**现金流久期**的影响。  
- 避免用单一美股隔夜涨跌解释 A 股全天走势；若引用外盘，须说明**传导渠道**（风险偏好、汇率、产业链）。

## 2. 行业与板块资金

- 结合 **行业/主题资金流向**（若提供板块资金流数据）：区分**持续流入**与**一日游**。  
- **申万/中信行业**相对收益：说明标的所属行业的**β**与个股**α**来源。  
- 周期 vs 成长：利率与增长预期切换时，估值锚（PEG、PB 分位）须与行业阶段一致。

## 3. 输出约束

- 宏观段落须包含：**当前环境判断（宽松/中性/收紧）+ 对标的所在板块的含义**。  
- 若板块数据缺失，写明「板块层面数据不足，行业结论置信度下降」。  
- VERDICT 中宏观方向须与**数据证据**一致，避免空泛口号。
