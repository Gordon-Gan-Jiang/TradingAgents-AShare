# A 股事件与舆情专项方法论（新闻 / 公告驱动）

> 与 FinSkills「事件驱动」类 Skill 对齐：**先区分事实与传言，再谈定价影响**。

## 1. 信息分层

- **一级**：交易所公告、监管层披露、公司法定披露（年报/问询函回复/重组预案）。  
- **二级**：权威媒体、交易所互动易回复。  
- **三级**：自媒体、论坛、未经核实的「小作文」。  
- 须在报告中标注信息层级；**三级信息不可单独支撑强结论**。

## 2. 事件类型与定价逻辑（A 股）

- **政策**：产业目录、补贴退坡、集采、环保与安全监管——评估对**收入/利润率**的传导路径与滞后。  
- **公司**：重组、定增、回购、股权激励、大股东增减持、质押率变化——区分**一次性**与**持续性**影响。  
- **行业**：景气度拐点、产能投放、价格战——结合**市占率**与**资本开支**判断持续性。  
- **市场结构**：涨跌停、停牌、ST 风险——须提示**流动性与规则约束**。

## 3. 输出约束

- 对每条重要事件给出：**事实摘要 → 影响方向 → 不确定性 / 待验证条件**。  
- 若新闻与基本面报告冲突，须**显式对比**并说明采信理由。  
- 禁止将单一传闻写成确定结论；文末 VERDICT 须与证据强度匹配。
