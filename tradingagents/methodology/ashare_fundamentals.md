# A 股基本面专项方法论（内置于 TradingAgents-AShare）

> 本文件为**可执行的检查清单**，用于约束基本面 Agent 在沪深北交所标的上的分析深度与可追溯性。  
> 可与外部 **FinSkills** 等仓库中的 `references/*.md` 通过环境变量 `TA_METHODOLOGY_EXTRA` 追加合并（见 `tradingagents.methodology.loader`）。

## 1. 数据与口径

- 明确所用报表为 **CAS（企业会计准则）** 口径；若存在 **追溯调整 / 会计政策变更**，须在结论中说明对可比性的影响。
- 同比、环比并列时，优先解释 **扣非净利润** 与 **经营现金流** 是否同向；若背离，必须展开原因（应收、存货、折旧、税费、一次性损益等）。

## 2. 利润质量

- **毛利率 / 净利率** 变动需拆到：价格、销量、成本、费用、减值、其他收益。
- 关注 **非经常性损益** 占比；若净利润依赖 **政府补助、资产处置、公允价值变动**，须单独标注可持续性风险。
- **研发费用资本化**（若适用）需评估资本化率变化及对当期利润的影响。

## 3. 资产负债表与现金流

- **经营现金流 / 净利润** 长期显著背离时，列为重点风险（回款、存货积压、渠道压货等假说需结合行业验证）。
- **应收 + 存货** 增速相对收入增速：若明显更快，需讨论坏账与跌价准备是否充分。
- **商誉** 余额、减值测试假设、并购标的业绩对赌完成情况；高商誉组合须给出压力情景描述。
- **有息负债** 结构（短债占比）、货币资金受限情况、**存贷双高** 等 A 股常见质疑点需主动排查或声明数据不足。

## 4. 治理与关联方（A 股特有风险）

- 若工具数据包含 **关联交易、股东质押、资金占用** 类信息，须在风险段讨论；无数据则写明「未获取关联交易明细，结论置信度受限」。
- **分红与再融资** 历史：若长期高比例融资、低现金分红，需与自由现金流匹配度一并评述。

## 5. 估值与市场预期

- 在 **PE、PB、EV/EBITDA**（数据允许时）之外，说明当前估值隐含的增长预期；若业绩增速无法支撑隐含预期，须明确「预期差」方向。
- A 股常见 **行业政策、监管口径** 若与标的相关，须在基本面部分点名，避免纯财务数字堆砌。

## 6. 输出约束（与系统 VERDICT 一致）

- 结论须与文末 `<!-- VERDICT: ... -->` 方向一致；若数据严重缺失，方向应偏 **中性/偏空** 并说明「不可判定」的原因。
- 禁止无数据支撑的精确目标价；若用户需要价位，使用区间或条件式表述（「若××条件满足，再考虑××」）。
