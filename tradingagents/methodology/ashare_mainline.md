# A 股市场主线识别与选股方法论（内置）

> 供 mainline_analyst / mainline_stock_selector 使用的规则化框架。所有数值判断以输入数据为准，禁止编造。

## 1. 主线判定的五个必要条件（缺一不可从严）

1. **持续性**：资金连续多日聚焦，非单日脉冲。参考 `excess_ret_5d`、`inflow_persistent`（今日与5日均净流入）。
2. **相对强弱**：板块涨幅跑赢全市场基准（沪深300 / 全A中位数）。绝对涨幅在普涨日失真。
3. **资金合力**：主力净流入规模居前，且 5 日维度持续（`net_inflow_5d` > 0）。
4. **量能确认**：板块换手/成交额放大（`turnover` 与历史相比）。
5. **催化驱动**：政策、产业事件、海外映射（如英伟达财报→CPO）。无催化支撑的高热度板块标为「游资脉冲」。

## 2. 阶段判定（heat × strength 组合）

| heat_score | strength_score | 阶段 | 操作含义 |
|---|---|---|---|
| 升 / 高 | 起步 / 低 | 发酵 | 关注确认信号，可轻仓试错 |
| 高 | 高 | 主升 | 强度最强段，但需防一致预期兑现 |
| 高位 | 走平 / 背离 | 高位分歧 | 谨慎，等方向选择 |
| 走弱 | 走弱 | 退潮 | 规避，反抽是离场机会 |

补充信号：
- `excess_ret_5d` 为负但 heat 高 → 当日脉冲/新发，需催化佐证，否则不升级为主线；
- `hist_available=False`（历史缺失）→ strength 可信度低，强制降一档。

## 3. 状态机（昨日主线 → 今日）

- **延续**：强度/热度维持，资金未撤 → 不重复输出，更新验证条件；
- **扩散**：主线内出现新细分/新龙头 → 标记扩散，提示新机会；
- **退潮**：强度/热度/资金背离，或验证条件触发 → 标记退潮，提示规避；
- **新发**：昨日无、今日高置信（且有催化）→ 输出新主线。

## 4. 情绪周期 gating

- 情绪温度 冰点(<25)：主线缺失概率高 → 只输出观察方向，不出股；
- 亢奋(>85)：谨防高潮接盘 → 主线需更严格验证，提示拥挤风险；
- 其余：正常输出。

## 5. 可证伪性（每条主线必须带验证条件）

示例：`明日板块指数不创新高且资金净流出 → 主线证伪`。
验证条件应具体、可量化、次日可对账。

## 6. 选股规则（selector）

1. 候选池限定：东财板块成分股（若可用）∪ 涨停池（按行业匹配）；ST/退市/停牌已剔除；
2. 分层：龙头（辨识度/资金聚焦）/ 中军（市值与流动性核心）/ 补涨（滞后套利，高风险）；
3. entry_hint 必须给介入位置（回踩均线、首板溢价观察等），禁止无脑追高；
4. 每主线最多 5 只，宁缺毋滥；候选池不足时明确标注"暂无可介入标的"；
5. 主线 confidence < 60 → 不输出该主线候选股。
